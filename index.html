Security Best Practices

  • Use 12-16 characters minimum (longer provides better security)
  • Combine uppercase, lowercase, numbers, and special characters
  • Avoid dictionary words, names, and keyboard patterns
  • Consider passphrases with random words separated by symbols
  • Use a reputable password manager for unique passwords
  • Enable two-factor authentication wherever possible
  • Never reuse passwords across different accounts
